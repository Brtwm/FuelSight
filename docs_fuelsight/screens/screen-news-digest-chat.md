## Route
`/news`

## Описание элементов
- Левая колонка контента посвящена digest и поиску по новостям.
- Правая колонка — чат с обязательным списком citations.
- Badge `LLM off` явно показывает, что генеративный контур может быть отключён.

## Интерактивность
- `[Показать источники]` раскрывает список новостей, использованных в digest.
- `[Обновить]` доступна только `admin` и инициирует refresh новостей.
- Отправка сообщения в чат создаёт запрос к RAG-сервису.
- Поиск по новостям остаётся доступным даже при `LLM off`.

## Responsive-заметки
- На tablet digest и chat становятся вкладками.
- На mobile список источников и citations лучше открывать в drawer, чтобы не перегружать экран.
