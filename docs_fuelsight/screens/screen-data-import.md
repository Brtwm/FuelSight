## Route
`/import`

## Описание элементов
- Левое меню повторяет основной shell приложения.
- Верхние табы переключают три режима: загрузка продаж, загрузка закупок и генерация демо-данных.
- Правая боковая карточка показывает ожидаемую схему файла.
- Нижняя таблица отражает историю импортов и статусы.

## Интерактивность
- `[Выбрать файл]` открывает системный file picker.
- `[Загрузить]` создаёт `import_job`.
- Переключение на `Демо-данные` открывает форму периода, набора продуктов и `seed`.
- Строка в истории импортов открывает детали job и список ошибок.

## Responsive-заметки
- На tablet блок со схемой файла уходит под карточку загрузки.
- На mobile режим истории импортов лучше открывать отдельным аккордеоном.
