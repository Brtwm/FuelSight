# Screen: Procurement and Margin Analytics

## Route
`/analytics/margin`

## ASCII-схема (desktop)
```text

│ [KPI]          │ Закупки и маржа                                                                         │
│ [Импорт]       │ [DT v] [01.02.2026 - 28.03.2026]                                         [Обновить]   │
```

## Описание элементов
- Главный график объединяет три ключевые серии: закупку, розницу и маржу.
- Левая нижняя таблица фокусируется на бизнес-порогах.
- Правая нижняя таблица фиксирует аномалии и причины.
- Текстовый блок внизу нужен для короткого бизнес-объяснения.

## Интерактивность
- Клик по дню ниже порога подсвечивает точку на графике.
- Клик по строке аномалии раскрывает детали и связанные новости.
- Смена продукта обновляет весь экран одной транзакцией данных.

## Responsive-заметки
- На tablet таблицы под графиком становятся accordion-блоками.
- На mobile пояснение причин переносится выше, чтобы пользователь не потерял контекст.
