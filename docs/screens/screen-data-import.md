## Описание элементов
- Левое меню повторяет основной shell приложения.
- Верхние табы показываются по роли: `sales` видит импорт продаж и историю
  продаж, `accounting` видит импорт закупок и историю закупок, `admin` видит
  продажи, закупки, историю, генерацию начальной истории и диагностику.
- Правая боковая карточка показывает ожидаемую схему файла.
- Нижняя таблица отражает историю импортов и статусы.

## Интерактивность
- `[Выбрать файл]` открывает системный file picker.
- `[Загрузить]` создаёт `import_job`.
- Переключение на `История импортов` у `admin` открывает форму периода, набора
  продуктов и `seed` для обновления начальной истории; для `sales` и
  `accounting` история доступна только для своего типа данных.
- Строка в истории импортов открывает детали job и список ошибок.

## Responsive-заметки
- На tablet блок со схемой файла уходит под карточку загрузки.
- На mobile режим истории импортов лучше открывать отдельным аккордеоном.
