# Screen: Login

## Route
`/login`

## Описание элементов
- Левая колонка кратко объясняет назначение системы.
- Правая карточка содержит поля `email`, `password` и primary action `Войти`.
- Ошибка авторизации показывается внутри карточки, без отдельного модального окна.

## Интерактивность
- `[Войти]` отправляет `POST /api/v1/auth/login`.
- Успешный логин ведёт на `/dashboard`.
- Ошибка остаётся на текущем экране и подсвечивает форму.

## Responsive-заметки
- На tablet/mobile левая колонка сворачивается в короткий верхний блок описания.
- Карточка входа остаётся по центру и занимает почти всю ширину экрана.
- Вертикальные отступы и типографика адаптированы для узкой ширины, чтобы экран входа оставался читаемым без zoom.
- Visual baseline: `Cinematic Dark` с technical grid/flow background; `FuelSight` является главным first-viewport сигналом без маркетингового hero/landing.
