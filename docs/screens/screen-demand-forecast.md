## Описание элементов
- Верхняя панель задаёт продукт, горизонт и сценарный режим.
- Центральный график является основным артефактом будущего прогноза.
- Блок `Качество и надёжность` показывает health модели, последние backtest metrics и `Качество модели`.
- `Качество модели` объясняет validation evidence через статус `OK`/`LIMITED`/`UNKNOWN`, причину статуса, train/test period, наблюдения, график тестового периода, таблицу `MAE`/`RMSE`/`SMAPE` и улучшение CatBoost относительно Seasonal Naive.
- Для `admin` внутри блока может быть раскрыт compact accordion с техническими деталями: тип окна, версия модели, дата обучения, режим данных, свежесть и retrain status.
- Таблица дублирует числовой прогноз для отчётности.

## Интерактивность
- `[Запустить]` вызывает `POST /api/v1/forecasts/run`.
- Включение `Scenario mode` добавляет вторую серию сравнения.
- При baseline fallback экран показывает warning badge рядом с метриками.
- Backtest run доступен только `admin`; текущие forecast-read роли видят core evidence последнего backtest.
- Если validation evidence отсутствует, блок показывает `UNKNOWN`; если evidence неполное, короткое или CatBoost хуже Seasonal Naive по `SMAPE`, блок показывает `LIMITED`.

## Responsive-заметки
- На tablet панели качества, таблица и драйверы складываются одна под другой.
- На mobile применён порядок чтения:
  1. controls;
  2. модельная health summary;
  3. forecast future chart;
  4. backtest metrics and validation evidence;
  5. values list.
- На mobile график будущего прогноза и validation chart тестового периода остаются визуально разными блоками, чтобы не смешивать будущую оценку с проверкой на истории.
- На mobile числовой блок прогноза рендерится карточками (`Base/Scenario/диапазон`) вместо широкой таблицы.
- Для chart на малой ширине используются короткие legend labels и скрытые по умолчанию интервальные серии.
- Видимые статусы прогноза локализованы: baseline fallback объясняется как `используется базовый прогноз`; отсутствующие значения отображаются `—`, а не raw `n/a`.
