# Screen: News Digest and Chat

## Route
`/news`

Frontend route доступен ролям `admin`, `analyst`, `director`. Backend RAG chat
actions доступны только `admin` и `analyst`; для `director` демонстрационный
сценарий ограничен новостной сводкой, поиском и рыночным контекстом.

## Описание элементов
- Левая колонка контента посвящена digest и поиску по новостям.
- Правая колонка — чат с обязательным списком citations для ролей, которым
  backend разрешает chat actions.
- Page-level badge `без генерации` явно показывает, что генеративный контур может быть отключён.
- При выключенной генерации чат остаётся доступным в retrieval-only режиме при наличии источников; digest и поиск остаются рабочими.

## Интерактивность
- `[Показать источники]` раскрывает список новостей, использованных в digest.
- `[Обновить]` доступна только `admin` и инициирует refresh новостей.
- Отправка сообщения в чат создаёт запрос к RAG-сервису для `admin` и `analyst`.
- Поиск по новостям остаётся доступным даже при `LLM off`.

## Responsive-заметки
- На tablet/desktop сохраняется split layout `digest+search` слева и `chat` справа.
- На mobile применён tab layout `[Сводка | Поиск | Чат]`.
- Фильтры поиска и source-кнопки настроены на перенос без horizontal overflow.
- Chat UI не показывает raw provider/model/degradation labels; assistant messages выделяются amber border, user messages — спокойным cyan/dark fill, citations остаются обязательным блоком ответа.
